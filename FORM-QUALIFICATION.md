# Formulaire de qualification Agent IA

Formulaire public : `https://tally.so/r/2EbyZL`

Le formulaire Tally a été restructuré et publié le 28 juillet 2026 sans envoyer de réponse de test.

## Champs publiés

1. Nom et prénom — obligatoire
2. Email professionnel — obligatoire
3. Entreprise — obligatoire
4. Site internet — facultatif
5. Fonction — obligatoire
6. Taille de l’entreprise — obligatoire
7. Tâche à automatiser — obligatoire
8. Nombre de personnes concernées — obligatoire
9. Fréquence de la tâche — obligatoire
10. Outils ou documents concernés — obligatoire
11. Résultat souhaité — obligatoire
12. Date de démarrage souhaitée — obligatoire
13. Budget envisagé — obligatoire
14. Informations complémentaires — facultatif
15. Consentement à l’utilisation des informations pour répondre — obligatoire

Le formulaire affiche avant l’envoi : « Ne transmettez aucun mot de passe, clé API ni document confidentiel dans ce formulaire. »

Le bouton est libellé « Envoyer ma demande ». La page de confirmation indique qu’une réponse personnalisée est généralement envoyée sous deux jours ouvrés et précise qu’un échange à distance n’est proposé que si le projet semble compatible.

## Contrôle effectué

- formulaire public chargé sans authentification ;
- ordre, libellés et choix contrôlés dans le DOM accessible ;
- champs facultatifs contrôlés sans astérisque ;
- consentement contrôlé comme obligatoire ;
- bouton et avertissement contrôlés ;
- aucune soumission réelle effectuée.
