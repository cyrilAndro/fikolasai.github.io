# Pilotage mensuel SEO et GEO

Mettre à jour `geo-monthly-dashboard.csv` avant le 5 de chaque mois.

## Sources

1. Google Search Console : impressions, clics, CTR et position moyenne.
2. Bing Webmaster Tools, rapport AI Performance : citations et pages citées.
3. Outil d’analytics : sessions provenant de ChatGPT, Perplexity, Copilot/Bing et autres assistants.
4. Tally ou CRM : prospects qualifiés attribuables à une visite provenant d’un assistant.

## Règles

- conserver les valeurs brutes exportées ;
- ne pas interpréter une absence de référent comme une absence d’influence de l’IA ;
- suivre la tendance sur plusieurs mois ;
- inscrire une seule action prioritaire par mois ;
- comparer les pages citées avec les pages qui génèrent réellement des prospects.

Le fichier CSV est compatible avec Excel, LibreOffice et Google Sheets. Les colonnes CTR et taux de prospect contiennent déjà leurs formules mensuelles.
